# Scenario playbooks

For each incident, answer these questions before changing anything:

1. What is the customer impact and blast radius?
2. What evidence distinguishes app, container, cluster, network, and dependency failure?
3. What is the safest mitigation that restores service?
4. How will you prove recovery?
5. What permanent action prevents recurrence?

Use a 60–90 second interview structure: **clarify impact → check signals → isolate layer → mitigate → validate → prevent**.
