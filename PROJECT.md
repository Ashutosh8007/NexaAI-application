# Project scope

**Name:** NexaAI DevOps Scenario Lab  
**Purpose:** Practice real-world DevOps incident response for a simulated AI/microservices platform.  
**Included:** GitHub Actions, Linux, Bash, Docker, Compose, Kubernetes, security scanning, observability/troubleshooting playbooks.  
**Excluded:** Terraform, real AI model hosting, real cloud deployment, production credentials.  
**Default environment:** local laptop and disposable Kubernetes cluster.
